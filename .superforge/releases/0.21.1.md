# 0.21.1 (2026-11-23)

Three guides for parts that had none, each a `README.md` in its folder,
and a few comments put right. Nothing the app does changes.

- **Logging in**, machinery: `source/backend/auth/README.md`, new. A login
  from the page to the session, what each refusal is, the session and its
  cookie, the team in code and in `users`, the four checks a route takes
  and what each puts on `context`, Claude's token and an API token, the
  place for someone besides the team to log in, the `prune-sessions` job,
  and logging someone in from a test.
- **Your files**, machinery: `source/backend/files/README.md`, new. The
  rows and the bucket, every route, an upload in a build and in a dev
  server, downloads and links, Trash, the folders the app keeps for
  itself, the limits, and what's left for an app to build.
- **The database**, machinery: `source/database/README.md`, new. A map of
  the folder: the schema's files and who owns each, migrations, the
  checkout's own Postgres, the seed, the bucket's kinds, and what the
  tests run on.
- **`workbench/writing-code.md`**'s "Each part's own guide" lists the
  three, and `CLAUDE.md` says each folder has one.
- **Comments**, machinery: `utilities/permissions.ts` is
  `utilities/permissions/` wherever it was named, `auth/others.ts` says a
  second kind of login ends whatever session the browser had, and a few
  that named something that isn't there any more are right.

A copy takes it as it is: new files, and comments.
